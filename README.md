# محاسبتي: بناء ملف التثبيت

المشروع ده بيحوّل الملف الموجود في المجلد www لتطبيق أندرويد، والبناء بيتم على جيت هاب من غير ما تثبّت حاجة عندك.

## الخطوات

1. اعمل مستودع جديد على جيت هاب (خاص أو عام).
2. ارفع كل محتويات المجلد ده فيه، ومعاها المجلد المخفي .github وملف debug.keystore.
3. افتح تبويب Actions في المستودع، واختار Build APK، واضغط Run workflow. (بيشتغل لوحده كمان مع أول رفع.)
4. استنى حوالي 5 إلى 10 دقايق لحد ما يظهر علامة صح خضرا.
5. افتح التشغيلة، ونزّل muhasabati-apk من قسم Artifacts، وفك الضغط، هتلاقي app-debug.apk.
6. ابعته للتليفون (واتساب أو درايف أو كابل)، وافتحه، واسمح بالتثبيت من مصادر غير معروفة لو سأل.

## بالأوامر

    git init
    git add .
    git commit -m "init"
    git branch -M main
    git remote add origin <رابط المستودع>
    git push -u origin main

## ملاحظات

- لما تعدّل www/index.html وترفعه، بيتبني ملف جديد، وتثبّته فوق القديم والبيانات بتفضل.
- النسخة موقّعة بمفتاح الاختبار الثابت debug.keystore، يعني مناسبة للاستخدام الشخصي، مش للنشر على متجر بلاي.
- التصدير (النسخة الاحتياطية وملف التقويم) جوه التطبيق بيفتح قائمة المشاركة، تحفظه في الملفات أو تبعته لنفسك.
- بياناتك بتتحفظ جوه التطبيق على التليفون، وبتتمسح لو مسحت التطبيق، فصدّر نسخة احتياطية كل فترة.
